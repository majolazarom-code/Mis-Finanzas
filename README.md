# Mi Finanzas — v9 (amarillo)

Abre `index.html` en Chrome. Conserva los datos locales bajo `mf-v5` en el mismo origen; antes de actualizar **exporta respaldo JSON** desde la versión anterior. Para uso en iPhone como PWA, publica por HTTPS.

## Novedades
- Calendario financiero con pagos previstos, pagados e ingresos/gastos reales.
- Repetición mensual: al visitar meses posteriores se generan las planificaciones recurrentes sin duplicados.
- Transferencias entre cuentas, sin modificar el balance global.
- Compras a cuotas: se generan cuotas planificadas y se registran como gasto solo al confirmarlas.
- Saldo proyectado: saldo real menos pagos pendientes del mes.

Los saldos son registros manuales, no conexiones bancarias. No hay notificaciones push. Prueba con datos ficticios y mantén respaldos.
